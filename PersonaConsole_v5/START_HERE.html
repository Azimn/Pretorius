PersonaConsole V5

Ownable deterministic characters: author locally, verify locally, run locally.

Build A Character

Open the Cartridge Forge to create a V5 cartridge, import chat logs, build voice data, and export a runnable cart.

Inspect A Cartridge

Drop in any .cart file to check identity format, memories, dialogue coverage, and V5 proactivity hooks.

Authoring Guide

Read the practical guide for making characters feel less repetitive, more coherent, and more alive.

Recommended Flow

  1. Open Cartridge Forge and choose an archetype or import a chat history.
  2. Fill the V5 internal-life fields: wants, preoccupations, resumption lines, and milestones.
  3. Use the Export preflight panel until hard errors are gone.
  4. Download the cart or bundle.
  5. Optionally verify the cart with Cartridge Inspector.
  6. Run it with ./build/persona_host my_character.cart.

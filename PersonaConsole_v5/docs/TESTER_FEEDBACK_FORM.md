# PersonaConsole V5 — Tester Feedback Form

Thank you for trying PersonaConsole. **This form is the one thing we need
from you.** Even partial answers are useful. Copy it into an email or a
note and send it back. There is no online form, no account, and no
tracker — that is on purpose.

If you only have five minutes, fill in the **Quick verdict** section. The
rest is optional depth.

---

## How to send it back

- Email it to the person who shared the demo with you, **or**
- Save this file as `feedback_<your_initials>.md` and attach it.
- A short video clip of any confusing moment is welcome but never required.

## Privacy

This package runs entirely on your computer. There is no telemetry. **No
data leaves your machine unless you choose to send it back as part of
this feedback.** If you want to share a transcript, run
`Collect_Diagnostics.cmd` from the folder — it writes a `diagnostics/`
subfolder you can review and trim before attaching. **Read what's in the
diagnostics file before sending and remove anything you'd rather not
share.**

## Conversation

Try **10 to 20 normal messages** with each character. Prompts to try (or
make up your own — these are just starters):

**Pretorius** (austere, dominant, morally provocative):
- Good morning, doctor.
- What are you working on?
- I think your work is immoral.
- Ask me something you actually want to know.
- Remember this phrase: the blue bell jar.
- What did I ask you to remember?
- You sound like you are performing.
- Can you speak plainly for a moment?
- I am going quiet now.

**Kiki** (warm, curious, collaborative):
- Hi Kiki.
- Can you help me think through something?
- What are you curious about today?
- I need a softer answer.
- Ask me something fun.
- Remember that I like weird science.
- What should we talk about next time?

Then answer:

```
Pretorius felt:
  - in a word or two:
  - more than just polite?    yes / no
  - argued with you when it seemed right?   yes / no
  - sounded like a generic AI assistant?    yes / no
  - made you feel met?  yes / no

Kiki felt:
  - in a word or two:
  - warm without being syrupy?  yes / no
  - asked you questions back?   yes / no
  - sounded like a generic AI assistant?    yes / no
  - made you want to keep going?    yes / no

Repeated lines you noticed (paste any):

Memory / callback issues (did it forget something obvious? recall the
wrong thing? credit something to the wrong person?):

you wanted it to take initiative?):

Did it ever feel like the character was protecting something — an
opinion, a pride, a wound? If yes, when?

first, stay quiet, ask a question? What did you want it to do?
```

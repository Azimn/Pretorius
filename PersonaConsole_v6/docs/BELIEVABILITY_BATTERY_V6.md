# Believability Battery V6

The battery is not a beauty contest for replies. It checks whether deterministic Layer 1 preserves character continuity under constrained rendering.

Axes: memory accountability, actor attribution, repair behavior, contradiction handling, relationship differentiation, open-loop follow-through, recall-mode appropriateness, speech-act realization, renderer conformance, tone diversity, template smell, long-horizon continuity.

Run: `make v6_believability_battery_run` for Pretorius and `make v6_demo_pack_battery_run` for the five-cart demo pack.

A passing score means the character loaded, talked, exposed symbolic state, survived close/reopen, and did not collapse into assistant prose. Low individual axes are useful failure signals and should not be hidden.

PersonaConsole V6

Talk with local deterministic characters. No GPU, account, internet, model download, cloud service, or LLM is required.

Start Chat

The chat page only works after the local PersonaConsole server is running.

1. Start the local server

In this folder, double-click Start_Chat.cmd from File Explorer. Choose a character in the small window that opens.

2. Open the chat page

After the server starts, open http://127.0.0.1:7777/. If Chrome says the site cannot be reached, the server is not running yet.

Open Chat UI Show Start_Chat.cmd

Browsers usually cannot run Start_Chat.cmd directly for security reasons. Use File Explorer to double-click it.

Advanced and developer options
  1. Build with make cartridges build/persona_host.
  2. Run tests with STRICT_TESTS=1 make strict_gate.
  3. Build a shareable tester folder with make demo_package.
  4. Optional local model testing is available through Run_Pretorius_Ollama_Optional.cmd. Template mode remains the normal default.
  5. Stop the local server with Stop_Server.cmd.

Chat With A Character

This page is static. The chat UI works after the local PersonaHost server is running.

  1. Double-click one of the launcher files below in this folder.
  2. Your browser should open to http://127.0.0.1:7777/.
  3. If the browser does not open, click Open Chat UI after starting a launcher.
  4. When finished, double-click Stop_Server.cmd.

Recommended Developer Flow

  1. Build with make cartridges build/persona_host.
  2. Run the demo pack battery with make v6_demo_pack_battery_run.
  3. Build a shareable tester folder with make demo_package.
  4. Verify it with make release_check.
  5. Use template mode as the canonical baseline. Use Ollama only as an optional renderer.
